## Clone Everything

Clone this repo, then run [clone-all.sh](https://github.com/liferay-se/.github/blob/main/clone-all.sh) — every repo you have access to is cloned as a sibling of this one:

```bash
mkdir liferay-se
cd liferay-se
gh repo clone liferay-se/.github
./.github/clone-all.sh
```

The script clones whatever your GitHub account can see: the public repos for everyone, plus the private ones if you are an organization member.
